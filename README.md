# PhysioCare
یک قالب فارسی و راست‌چین برای کتابخانه تمرین‌های فیزیوتراپی.

## اجرا
فایل `index.html` را در مرورگر باز کنید.

## انتشار در GitHub Pages
یک repository بسازید، سه فایل `index.html`، `style.css` و `script.js` را آپلود کنید، سپس در Settings → Pages، شاخه `main` و پوشه `/root` را انتخاب کنید.
